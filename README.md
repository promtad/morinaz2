# وردة — نسخة Vite (موقع ثابت)

نسخة Vite + React من واجهة متجر **وردة** للعروض النسائية (عربي / English)، تعمل كموقع ثابت بدون خادم أو قاعدة بيانات. العضوية والمفضلة في هذه النسخة تجريبية وتُحفظ في متصفح الزائرة فقط (localStorage).

## بنية المجلدات (كما في الصورة)

- `public/` — الصور والملفات الثابتة (`ads.txt`، الأيقونة، حزمة إضافة ووردبريس).
- `src/` — شيفرة الموقع (`main.tsx`، `App.tsx`، `data.ts`، `styles.css`).
- `index.html` — الصفحة الرئيسية.
- `package.json` — الحزم والأوامر.
- `package-lock.json` — يُنشأ تلقائيًا عند أول `npm install`.
- `tsconfig.json` — إعدادات TypeScript.
- `vite.config.ts` — إعدادات Vite.
- `node_modules/` — تُنشأ تلقائيًا بعد `npm install`.
- `dist/` — تُنشأ تلقائيًا بعد `npm run build` وهي الملفات الجاهزة للنشر.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتحي الرابط الذي يظهر لكِ (عادة `http://localhost:5173`).

## بناء نسخة النشر

```bash
npm run build
```

ستجدين الملفات الجاهزة داخل مجلد `dist/` — ارفعي محتوياته إلى أي استضافة ثابتة.

## تعديل المحتوى

- العروض والأقسام والإعلانات واسم الموقع: عدّلي ملف `src/data.ts`.
- لإضافة إعلان: أضيفي عنصرًا إلى مصفوفة `ADS` مع `placement` من القيم: `header` أو `middle` أو `sidebar` أو `footer`.
- ملف المعلنين: عدّلي `public/ads.txt` مباشرة.

## ملاحظة

هذه النسخة للعرض والتجربة السريعة. النسخة الكاملة بقاعدة البيانات ولوحة الإدارة هي نسخة Next.js + PostgreSQL، وتوجد أيضًا إضافة ووردبريس جاهزة في `public/warda-marketplace.zip`.
